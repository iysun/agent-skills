# Markdown 转演示 HTML

把用户的 **Markdown 大纲或文档**，转换成一份**自包含、可直接在浏览器演示的 HTML 幻灯片**（默认简体中文；用户要求英文再切换）。产物不依赖网络，双击即可放映。

## 触发与边界

**应触发：**
- 「把这份大纲/文档/md 做成幻灯片 / PPT / 演示 HTML」
- 「做个用于录屏 / 路演 / 分享会的 slides / 演示页面」
- 用户给出 md 内容 + 想要可视化演示时

**不触发：**
- 用户要的是 `.pptx` 二进制文件（说明本 skill 产出 HTML，可按需 PDF 导出后再转，或询问是否接受 HTML）
- 纯文档排版、博客页面，而非「一页一页放映」的演示场景

## 核心资产

- **模板**：[assets/template.html](assets/template.html) —— 单文件，含全部布局、主题系统与放映脚本。**生成时以它为基准**，只替换 `<main class="deck">…</main>` 内的 `.slide`，其余（`<style>`、控制栏、`<script>`）原样保留。
- **布局与主题速查**：[reference.md](reference.md) —— 每种布局的 HTML 片段、主题/主题色清单、快捷键。
- **完整示例**：[examples.md](examples.md) —— 一段 md 大纲 → 成品幻灯片的对照。

## 工作流程

### 1. 读输入，定结构

读取用户的 md（文件或粘贴内容）。把它**映射成一串幻灯片**，每个一级/二级标题通常对应一页或一节：

- 文档标题 → **封面**（cover）
- 每个大章节 → 一张**分隔页**（section）+ 若干内容页
- 并列要点 → **bullets** 或 **2×2 / 三栏** 卡片
- 「A 还是 B / 对比 / 优劣」→ **compare**
- 金句、结论、转折 → **statement / quote**
- 流程、时间线、步骤 → **steps**
- 代码、命令 → **code**；截图、图表 → **figure**
- 收尾 / 行动号召 → **end**

**控制节奏**：一页只讲一个点；要点超过 5 条就拆页或改用卡片。演示稿宁可多页、每页少字，不要把段落整段塞进一页。

不确定整体结构或主题色偏好时，可先给用户一个**一句话页面清单**确认，再生成。

### 2. 扩展内容（重要）

大纲往往只有关键词。**为每页补齐可照着讲的措辞**：把关键词扩成完整短句、补一句支撑论据或例子、提炼出每页的「一句话主张」。但**不要编造事实**（数据、引用、出处）——拿不准的留占位或提示用户补充。

为关键页加 `data-notes="…"` 写**演讲备注**（放映时按 `S` 显示），帮助用户口播。

### 3. 选布局，填内容

从 [reference.md](reference.md) 取对应布局片段，填入真实内容。规则：

- **保持 class 名不变**（主题与脚本依赖它们）。
- 强调用 `<span class="hl">`、`<span class="hl2">`、`<span class="grad">`。
- 同一份演示里**布局要有变化**，避免十页都是 bullets——交替使用分隔页 / 卡片 / 金句 / 对比，观感更好。
- 图片：本地图用相对路径，并提示用户把图放到 HTML 同目录；没有图时用 `figure` 占位并标注「替换 src」。

### 4. 设主题与主题色

在 `<html data-theme="…" data-accent="…">` 上设默认值（见 reference）。按内容气质选：

- 技术/极客 → `midnight` 或 `slate` + `blue`/`cyan`
- 温暖/分享 → `dawn` + `orange`/`pink`
- 浅色/正式 → `paper` + `blue`/`green`

无论默认值如何，用户放映时都能用顶部「🎨 主题」面板或快捷键 `T`/`C` 实时切换，并记忆到 `localStorage`。

### 5. 输出文件

- 默认写到**与源 md 同目录**，文件名 `<源名>.slides.html`（或用户指定）。
- 用 Write 工具一次写出完整 HTML。
- 写完告诉用户：**文件路径、页数、当前主题、快捷键**，并提示双击用浏览器打开。

## 放映与导出能力（告知用户）

| 操作 | 方式 |
|------|------|
| 翻页 | `A` 上一页 / `D` 下一页（或 `←` `→` `空格`，或**双击**屏幕左/右半边） |
| 跳转 | `Q` 首页 / `E` 末页（或 `Home` / `End`）；URL `#3` 直接定位第 3 页 |
| 全屏 | `F`（录屏前按一下更干净） |
| 总览 | `V`（或 `O`）开关；总览内 `WASD`（或方向键）移动高亮、`空格`/`Enter` 进入、`Esc` 退出，也可鼠标点击跳页 |
| 演讲备注 | `S`（显示当前页 `data-notes`） |
| 切主题 / 主题色 | `T` / `C`，或点右上角「🎨 主题」 |
| 导出 PDF | 浏览器打印（`Ctrl/Cmd+P`）→ 另存为 PDF，每页一张幻灯片（已配 `@media print`） |

## 质量要求

- **单文件自包含**：CSS、JS 内联，不引外部库；可离线、可直接发给别人。
- **不破坏结构**：只改 `.slide` 内容与 `data-theme`/`data-accent`，保留脚本与样式。
- **不编造**：事实、数据、引用须来自用户输入；扩写的是表达，不是事实。
- **录屏友好**：大字号、高对比、留白充足，关键页配备注。
- 用户未指定语言时，**全文简体中文**。
